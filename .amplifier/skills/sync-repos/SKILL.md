# Sync Repos Skill

Synchronize all tracked git repositories from the repos.json inventory.

## When to Use

- User says "sync all repos" or "pull all repos"
- User wants to catch up on a new machine
- Part of morning routine workflows
- Before starting work to get latest changes

## Python API (Preferred)

```python
from amplifier.skills import (
    sync_all, sync_all_sync, sync_repo,
    get_repos, get_repo_status, Repo, SyncResult
)

# Sync all repos (async)
results = await sync_all()
for r in results:
    status = "✓" if r.success else "✗"
    print(f"{status} {r.name}: {r.message}")

# Sync with push
results = await sync_all(push=True)

# Synchronous version
results = sync_all_sync(push=True)

# Sync a single repo
success, message = await sync_repo("~/projects/my-repo")
success, message = await sync_repo("~/projects/my-repo", push=True)

# Get list of tracked repos
repos = get_repos()
for repo in repos:
    print(f"{repo.name}: {repo.local_path}")

# Get status of a repo
status = get_repo_status("~/projects/my-repo")
print(f"Branch: {status['branch']}")
print(f"Ahead: {status['ahead']}, Behind: {status['behind']}")
print(f"Dirty: {status['dirty']}")
```

## Data Classes

```python
@dataclass
class Repo:
    name: str
    local_path: str
    remote_url: str | None = None
    branch: str | None = None

@dataclass
class SyncResult:
    name: str
    path: str
    success: bool
    message: str
```

## repos.json Location

Default: `~/switchboard/amplifier/repos.json`

Generated by: `cd ~/obs-dailynotes && npm run repos:scan`

## CLI Interface

```bash
# Sync all (pull only)
python -m amplifier.skills.sync_repos

# Sync with push
python -m amplifier.skills.sync_repos --push

# Output as JSON
python -m amplifier.skills.sync_repos --json

# List tracked repos
python -m amplifier.skills.sync_repos list

# Get status of specific repo
python -m amplifier.skills.sync_repos status ~/projects/my-repo

# Custom repos.json location
python -m amplifier.skills.sync_repos --repos-file /path/to/repos.json
```

## Integration with Morning Routine

```python
from amplifier.skills import sync_all_sync

# Pull all repos at start of day
results = sync_all_sync()
synced = sum(1 for r in results if r.success)
print(f"Synced {synced}/{len(results)} repos")
```

## Error Handling

The skill handles common git errors gracefully:
- Repo not found locally
- Not a git repository
- Network timeouts (30s default)
- Merge conflicts (reports error, doesn't break)

## Advantages Over Script

- ✅ Works in subagents
- ✅ Async-first with sync wrapper
- ✅ Returns structured results
- ✅ Built-in status checking
